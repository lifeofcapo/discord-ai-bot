# The Merchant Standard — Discord Bot

## Запуск с нуля

1. Установите Python 3.11+ (проверить: `python3 --version`)
2. Создайте виртуальное окружение:
   ```
   python3 -m venv venv
   source venv/bin/activate   # на Windows: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и вставьте туда токен бота из Developer Portal:
   ```
   cp .env.example .env
   ```
5. Запустите бота:
   ```
   python main.py
   ```

## Проверка, что всё работает

- В консоли должно появиться: `Бот вошёл в систему как ...` и `Синхронизировано команд: 1`
- В Discord бот должен стать "онлайн" (зелёная точка)
- В любом текстовом канале, где у бота есть доступ, наберите `/ping` — должен ответить "🏓 Pong!"

Если `/ping` не появляется в списке команд сразу — подождите пару минут, Discord иногда кэширует список слэш-команд на своей стороне.
